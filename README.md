# Мини-игры

Небольшие игры и тренажёры для браузера.

- [Латинские буквы](https://play.ashva.ru/type/) — название буквы звучит по-английски, ответ клавишей A–Z или экранной клавиатурой. Верно +1, ошибка −1. Пробел повторяет букву. Счёт хранится в браузере на устройстве.

Для локального запуска: `python3 -m http.server 8793`, затем открыть http://localhost:8793/type/.

Статический HTML, CSS и JavaScript. Озвучка использует голоса браузера/ОС, звуки успеха — Web Audio. Нужен браузер с поддержкой SpeechSynthesis. Хостинг: GitHub Pages.
